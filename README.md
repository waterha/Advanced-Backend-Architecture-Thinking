1、域名服务器分四种（按广到细顺序）： 1.根域名服务器（.）；2.顶级域名服务器（.com）；3.权威域名服务器（.baidu）；4.本地域名服务器。 这些组成（www.baidu.com.）
2、域名解析是递归查询的（比如www.baidu.com是本地域名服务器先自查缓存，没有就去根服务器查、然后根服务器给了顶级服务器的ip地址，然后本地服务器去顶级服务器查，以此类推最后查完）
3、代理是位于客户端和服务端中间的节点（客户端——代理——服务端），可以理解为中间层
4、反向代理是客户端发起请求后，代理层以自己的身份重新，向目标服务端发送请求，再把响应经过自己返回给客户端，做改写和路由作用（比如在校外访问校内需要用vpn，这vpn就是反向代理，技术栈代表：Nginx）
5、正向代理客户端主动配置代理地址，把请求发给代理，由代理代替客户端去访问目标服务器
6、正向和反向代理区别在于：正向是显性可见的、反向是隐藏不可见的
